# counter-strike-hacking
Materials for The Hack Pack meetings on Counter Strike (1.6) hacking

The [client lab instructions](lab/README.md) cover installation, feature controls,
memory tools, building from source, and rollback. The reversible Linux overlay
is in `lab/dist/hackpack-overlay-linux-x86_64.tar.gz`; the prepared Linux game
runtime and game assets are supplied separately.
See [verification evidence](lab/evidence/README.md) for the actual measurements.

See [server/README.md](server/README.md) for the containerized CS16Client-compatible
dedicated server, connection instructions, and UDP connectivity checks.
